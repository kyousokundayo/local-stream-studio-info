Local Stream Studio

Mac で画面・カメラ・音声を組み合わせ、YouTube または Twitch へのライブ配信と録画を操作できるデスクトップアプリです。

YouTube で配信を始める

  1. チャンネルを連携する。 アプリの「設定」→「YouTube連携」→「チャンネルを追加」から、ブラウザで Google にログインし、配信に使うチャンネルを選びます。
  2. 配信先を確かめる。 「YouTube」タブでチャンネル名を確かめます。配信開始画面で、予約済みの枠を選ぶか、新しい枠のタイトル・公開範囲・子ども向けかどうかを指定します。
  3. 映像を送る。 「YouTubeで配信開始」を押すと、選んだ枠へ映像と音声を送ります。配信中は別のタブを見ていても、送信先の表示で本番の配信先を確認できます。

配信中と配信後にできること

ライブチャットを読んだり、連携したチャンネルとしてコメントを送ったりできます。コメントを配信画面に載せることや、音声で読み上げることもできます。

「統計」では YouTube が提供する再生回数や高評価数と、この Mac で受信したコメント件数・参加者を確認できます。複数チャンネルを連携した場合は「保存済みチャンネル」で切り替えられます。

Google との連携について

チャンネルや配信枠の取得、配信の開始・終了、コメント投稿に YouTube API Services を使用します。データの保存期間と連携を解除する手順は、プライバシーポリシーで確認できます。
